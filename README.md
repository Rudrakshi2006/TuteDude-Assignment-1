# TuteDude-Assignment-1
Task 1: Basic Mathematical Operations
This program takes two numbers from the user.
It performs addition, subtraction, multiplication, and division on the numbers.
The results of all operations are shown on the screen.

Task 2: Personalized Greeting
This program takes the user’s first name and last name.
It joins both names to make a full name.
Then it prints a greeting message using the full name.
